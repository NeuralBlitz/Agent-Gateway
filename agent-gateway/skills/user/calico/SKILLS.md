# Calico Skill

Calico networking and policy.

## Commands

### Status
```
/calico status
```
Show Calico status.

### Node
```
/calico node
```
List nodes.

### Node Status
```
/calico node status <node>
```
Node status.

### Profile
```
/calico profile
```
List profiles.

### Policy
```
/calico policy
```
List policies.

### Tier
```
/calico tier
```
List network tiers.

### Host Endpoint
```
/calico hep
```
List host endpoints.

### Workload Endpoint
```
/calico wep
```
List workload endpoints.

### Felix Config
```
/calico felix
```
Felix configuration.

### IPAM
```
/calico ipam
```
IPAM status.

### IPPool
```
/calico ippool
```
List IP pools.

### BGPPeer
```
/calico bgp
```
List BGP peers.

### GlobalNetworkSet
```
/calico gns
```
List global network sets.

### NetworkSet
```
/calico netset
```
List network sets.

### Convert
```
/calico convert <file>
```
Convert policy.

## Examples

```
/calico status
/calico node
/calico node status node-1
/calico profile
/calico policy
/calico tier
/calico hep
/calico wep
/calico felix
/calico ipam
/calico ippool
/calico bgp
/calico gns
/calico netset
/calico convert policy.yaml
```
