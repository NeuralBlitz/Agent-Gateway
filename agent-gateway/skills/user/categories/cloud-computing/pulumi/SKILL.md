# Pulumi

Pulumi is an infrastructure as code platform that lets you use general-purpose programming languages to define and deploy cloud infrastructure on any cloud.

## Key Concepts

- Language SDKs (Python, Go, JS, TS)
- State management
- Cloud providers
- Config and secrets
- Crossguard for policy

## Common Use Cases

- Multi-cloud infrastructure
- Kubernetes deployments
- Serverless applications
- Policy as Code
- GitOps infrastructure

## Best Practices

- Use proper project structure
- Enable state encryption
- Implement CI/CD integration
- Use policy as code (Crossguard)
- Leverage native providers
