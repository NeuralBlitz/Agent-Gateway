# Checkmarx

Checkmarx is an application security testing platform providing static (SAST), dynamic (DAST), and software composition analysis (SCA). It offers wide language and framework support.

## Key Concepts

- SAST (Static Analysis)
- DAST (Dynamic Analysis)
- SCA (Software Composition Analysis)
- Codebashing (training)
- CxIAST (interactive testing)

## Common Use Cases

- Application security testing
- Compliance automation
- DevSecOps integration
- Security training
- Risk assessment

## Best Practices

- Integrate into SDLC
- Prioritize critical findings
- Use CxSAST queries
- Train developers
- Track remediation metrics
