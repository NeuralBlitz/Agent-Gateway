# Fortify

Micro Focus Fortify is an enterprise application security platform providing static, dynamic, and interactive testing. It offers comprehensive coverage and detailed remediation guidance.

## Key Concepts

- Fortify Static Code Analyzer (SCA)
- Fortify WebInspect (DAST)
- Fortify Audit Workbench
- Fortify SSC (Software Security Center)
- Fortify on Demand (SaaS)

## Common Use Cases

- Enterprise security testing
- Compliance reporting
- Secure SDLC
- Vulnerability management
- Security training

## Best Practices

- Integrate with build systems
- Use custom rules
- Configure quality gates
- Track KPIs
- Integrate with issue trackers
