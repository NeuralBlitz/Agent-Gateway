# Snyk

Snyk is a developer-first security platform that identifies and fixes vulnerabilities in code, dependencies, containers, and infrastructure as code.

## Key Concepts

- SCA (Software Composition Analysis)
- Container scanning
- IaC scanning
- License compliance
- Fix pull requests

## Common Use Cases

- Dependency vulnerability scanning
- Container security
- Infrastructure as Code security
- License compliance
- Shift-left security

## Best Practices

- Integrate into CI/CD early
- Prioritize fix PRs
- Configure ignore policies
- Use Snyk CLI locally
- Monitor trend dashboards
