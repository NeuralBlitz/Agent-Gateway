# New Relic

New Relic is a observability platform offering application monitoring, infrastructure monitoring, and digital intelligence. It provides comprehensive visibility into system performance.

## Key Concepts

- APM (Application Performance Monitoring)
- Browser monitoring
- Infrastructure monitoring
- Log management
- Synthetics

## Common Use Cases

- Application performance
- User experience monitoring
- Infrastructure insights
- Error tracking
- Capacity planning

## Best Practices

- Deploy agents comprehensively
- Configure appropriate sampling
- Use service maps for dependencies
- Set up alert policies
- Implement distributed tracing
