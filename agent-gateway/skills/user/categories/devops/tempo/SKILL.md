# Tempo

Tempo is an open-source, easy-to-use, high-scale distributed tracing backend. It provides cost-effective trace storage with minimal operational overhead.

## Key Concepts

- Trace ingestion (OTLP, Jaeger, Zipkin)
- TraceQL query language
- Object storage backend
- Wal-g integration
- Grafana integration

## Common Use Cases

- Distributed tracing
- Trace storage and retrieval
- Cost-effective tracing
- Grafana dashboards
- Performance monitoring

## Best Practices

- Use appropriate storage backend
- Configure trace retention
- Set up proper sampling
- Use TraceQL effectively
- Integrate with Loki for logs
