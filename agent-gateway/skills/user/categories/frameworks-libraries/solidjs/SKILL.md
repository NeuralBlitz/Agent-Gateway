# SolidJS

SolidJS is a declarative JavaScript library for building user interfaces. It uses fine-grained reactivity without a virtual DOM, providing excellent performance.

## Key Concepts

- Fine-grained reactivity
- Signals and effects
- No virtual DOM
- JSX compilation
- Store patterns

## Common Use Cases

- Interactive UIs
- Component libraries
- High-performance dashboards
- Mobile with SolidStart
- Progressive web apps

## Best Practices

- Use signals for state
- Leverage derived state
- Use stores for complex state
- Test with Solid Testing Library
- Consider SolidStart for SSR
