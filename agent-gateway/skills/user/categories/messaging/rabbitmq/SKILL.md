# RabbitMQ

RabbitMQ is a reliable messaging broker supporting multiple messaging protocols. It provides flexible routing, high availability, and enterprise features.

## Key Concepts

- Exchanges, queues, bindings
- Direct, topic, fanout, headers exchanges
- Publisher confirms
- Consumer acknowledgments
- Shovel and federation plugins

## Common Use Cases

- Task queues
- Request/reply patterns
- Event distribution
- Message routing
- Background job processing

## Best Practices

- Use appropriate exchange types
- Implement dead letter queues
- Configure TTL appropriately
- Use publisher confirms
- Monitor queue depths
