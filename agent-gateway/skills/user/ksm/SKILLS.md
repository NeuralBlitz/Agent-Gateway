# Kube-State-Metrics Skill

Kubernetes cluster state.

## Commands

### Metrics List
```
/ksm metrics
```
List available metrics.

### Pod Metrics
```
/ksm pods
```
Pod metrics.

### Deployment Metrics
```
/ksm deployments
```
Deployment metrics.

### Node Metrics
```
/ksm nodes
```
Node metrics.

### Service Metrics
```
/ksm services
```
Service metrics.

### Job Metrics
```
/ksm jobs
```
Job metrics.

### PV Metrics
```
/ksm persistentvolumes
```
PV metrics.

### PVC Metrics
```
/ksm persistentvolumeclaims
```
PVC metrics.

### ReplicaSet Metrics
```
/ksm replicasets
```
ReplicaSet metrics.

### StatefulSet Metrics
```
/ksm statefulsets
```
StatefulSet metrics.

### Endpoint Metrics
```
/ksm endpoints
```
Endpoint metrics.

### Ingress Metrics
```
/ksm ingresses
```
Ingress metrics.

### HPAMetrics
```
/ksm hpa
```
Horizontal Pod Autoscaler metrics.
