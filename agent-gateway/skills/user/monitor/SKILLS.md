# Monitor Skill

System monitoring and metrics.

## Commands

### System Monitor
```
/monitor system
```
Show system metrics (CPU, memory, disk).

### CPU Usage
```
/monitor cpu
```
Show CPU usage per core.

### Memory
```
/monitor memory
```
Show memory usage.

### Disk
```
/monitor disk
```
Show disk usage.

### Network
```
/monitor network
```
Show network I/O.

### Processes
```
/monitor processes [count]
```
Show top processes.

### IO Stats
```
/monitor io
```
Show I/O statistics.

### Load Average
```
/monitor load
```
Show system load.

### Uptime
```
/monitor uptime
```
Show system uptime.

### Who
```
/monitor who
```
Show logged in users.

### Stats Summary
```
/monitor summary
```
Show quick stats summary.

## Examples

```
/monitor system
/monitor cpu
/monitor memory
/monitor disk
/monitor network
/monitor processes 20
/monitor load
/monitor summary
```
