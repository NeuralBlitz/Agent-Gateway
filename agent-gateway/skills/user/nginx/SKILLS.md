# Nginx Skill

Nginx web server management.

## Commands

### Start
```
/nginx start
```
Start Nginx.

### Stop
```
/nginx stop
```
Stop Nginx.

### Restart
```
/nginx restart
```
Restart Nginx.

### Reload
```
/nginx reload
```
Reload configuration.

### Test Config
```
/nginx test
```
Test configuration syntax.

### Show Config
```
/nginx config
```
Show main config.

### List Sites
```
/nginx sites
```
List enabled sites.

### Enable Site
```
/nginx enable <site>
```
Enable site.

### Disable Site
```
/nginx disable <site>
```
Disable site.

### Logs
```
/nginx logs [type]
```
Show logs (access, error).

### Status
```
/nginx status
```
Show Nginx status.

### Connections
```
/nginx connections
```
Show active connections.

## Examples

```
/nginx start
/nginx stop
/nginx restart
/nginx reload
/nginx test
/nginx sites
/nginx enable mysite
/nginx disable mysite
/nginx logs error
/nginx status
```
