# Node Skill

Node.js runtime.

## Commands

### Version
```
/node version
```
Show version.

### Run Script
```
/node run <file>
```
Run script.

### REPL
```
/node repl
```
Start REPL.

### Check Syntax
```
/node check <file>
```
Check syntax.

### Eval
```
/node eval <code>
```
Eval code.

### Package Info
```
/node package <name>
```
Show package info.

### Modules Path
```
/node modules-path
```
Show modules path.

### Config
```
/node config
```
Show config.

### Deps
```
/node deps <file>
```
Show deps.

### Feature List
```
/node features
```
Show features.

### V8 Version
```
/node v8
```
Show V8 version.

### Process Info
```
/node process
```
Show process info.

## Examples

```
/node version
/node run script.js
/node repl
/node check app.js
/node eval "console.log('hello')"
/node package lodash
/node modules-path
/node config
/node deps app.js
/node features
/node v8
/node process
```
