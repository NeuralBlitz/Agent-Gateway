# NPM Skill

Node.js package management.

## Commands

### Install
```
/npm install [package]
```
Install package(s).

### Install Global
```
/npm install-global <package>
```
Install globally.

### Uninstall
```
/npm uninstall <package>
```
Remove package.

### Update
```
/npm update [package]
```
Update package(s).

### List
```
/npm list [package]
```
List installed packages.

### Outdated
```
/npm outdated
```
Show outdated packages.

### Audit
```
/npm audit
```
Audit dependencies.

### Audit Fix
```
/npm audit-fix
```
Fix vulnerabilities.

### Run Script
```
/npm run <script>
```
Run npm script.

### Init
```
/npm init
```
Initialize package.

### Publish
```
/npm publish
```
Publish package.

### View
```
/npm view <package>
```
View package info.

### Docs
```
/npm docs <package>
```
Open package docs.

### Deprecate
```
/npm deprecate <package> <message>
```
Deprecate package.

### Cache
```
/npm cache clean
```
Clean cache.

## Examples

```
/npm install lodash
/npm install -g typescript
/npm uninstall old-package
/npm update
/npm list
/npm outdated
/npm audit
/npm audit-fix
/npm run build
/npm run dev
/npm init
/npm publish
/npm view react
/npm docs lodash
/npm cache clean
```
