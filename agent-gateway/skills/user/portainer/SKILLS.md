# Portainer Skill

Container management UI.

## Commands

### Status
```
/portainer status
```
Show status.

### Containers
```
/portainer containers
```
List containers.

### Images
```
/portainer images
```
List images.

### Networks
```
/portainer networks
```
List networks.

### Volumes
```
/portainer volumes
```
List volumes.

### Stacks
```
/portainer stacks
```
List stacks.

### Create Stack
```
/portainer stack create <name>
```
Create stack.

### Templates
```
/portainer templates
```
List app templates.

### Endpoints
```
/portainer endpoints
```
List endpoints.

### Users
```
/portainer users
```
List users.

### Teams
```
/portainer teams
```
List teams.

### Logs
```
/portainer logs <container>
```
Container logs.

### Inspect
```
/portainer inspect <container>
```
Inspect container.

## Examples

```
/portainer status
/portainer containers
/portainer images
/portainer networks
/portainer volumes
/portainer stacks
/portainer stack create myapp
/portainer templates
/portainer endpoints
/portainer users
/portainer teams
/portainer logs web
/portainer inspect web
```
