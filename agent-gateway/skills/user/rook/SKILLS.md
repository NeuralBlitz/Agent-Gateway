# Rook Skill

Rook storage orchestrator.

## Commands

### Ceph Status
```
/rook ceph status
```
Show Ceph cluster status.

### Ceph Health
```
/rook ceph health
```
Show Ceph health.

### Ceph Osd
```
/rook ceph osd
```
List OSDs.

### Ceph Pools
```
/rook ceph pools
```
List pools.

### Ceph PG
```
/rook ceph pg
```
Show placement groups.

### Ceph RBD
```
/rook ceph rbd
```
RBD devices.

### Ceph FS
```
/rook ceph fs
```
Ceph filesystems.

### Ceph Config
```
/rook ceph config
```
Show configuration.

### Ceph Auth
```
/rook ceph auth
```
Show auth entries.

### Ceph DF
```
/rook ceph df
```
Show data usage.

### Block Pool
```
/rook blockpool
```
List block pools.

### Object Store
```
/rook object
```
List object stores.

### Bucket
```
/rook bucket
```
List buckets.

### Volumes
```
/rook volumes
```
List volumes.
