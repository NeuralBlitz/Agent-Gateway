# Skaffold Skill

Kubernetes development tool.

## Commands

### Init
```
/skaffold init
```
Initialize skaffold.

### Build
```
/skaffold build
```
Build images.

### Deploy
```
/skaffold deploy
```
Deploy to cluster.

### Dev
```
/skaffold dev
```
Run in dev mode.

### Run
```
/skaffold run
```
Run pipeline once.

### Delete
```
/skaffold delete
```
Delete deployed resources.

### Render
```
/skaffold render
```
Render manifests.

### Analyze
```
/skaffold analyze
```
Analyze project.

### Config List
```
/skaffold config list
```
List configurations.

### Config Set
```
/skaffold config set <key> <value>
```
Set configuration.

### Debug
```
/skaffold debug
```
Run in debug mode.

### Profile List
```
/skaffold profile list
```
List profiles.

### Profile Active
```
/skaffold profile active
```
Show active profile.

## Examples

```
/skaffold init
/skaffold build
/skaffold deploy
/skaffold dev
/skaffold run
/skaffold delete
/skaffold render
/skaffold analyze
/skaffold config list
/skaffold config set default-repo myrepo
/skaffold debug
/skaffold profile list
/skaffold profile active
```
