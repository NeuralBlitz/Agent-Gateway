# Terraform Skill

Infrastructure as Code with Terraform.

## Commands

### Init
```
/terraform init
```
Initialize Terraform.

### Plan
```
/terraform plan
```
Show execution plan.

### Apply
```
/terraform apply
```
Apply changes.

### Destroy
```
/terraform destroy
```
Destroy resources.

### Validate
```
/terraform validate
```
Validate configuration.

### Format
```
/terraform format
```
Format code.

### State List
```
/terraform state-list
```
List resources in state.

### State Show
```
/terraform state-show <resource>
```
Show resource details.

### Output
```
/terraform output
```
Show outputs.

### Refresh
```
/terraform refresh
```
Refresh state.

### Graph
```
/terraform graph
```
Show resource graph.

### Import
```
/terraform import <id> <address>
```
Import existing resource.

### Workspace List
```
/terraform workspace list
```
List workspaces.

### Workspace New
```
/terraform workspace new <name>
```
Create workspace.

### Workspace Select
```
/terraform workspace select <name>
```
Switch workspace.

## Examples

```
/terraform init
/terraform plan
/terraform apply
/terraform destroy
/terraform validate
/terraform format
/terraform state-list
/terraform output
/terraform workspace list
/terraform workspace new production
```
