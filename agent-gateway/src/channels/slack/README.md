# Slack Channel (`src/channels/slack/`)

> **Slack Web API adapter — send and receive messages via Slack with Block Kit support.**

---

## Overview

The `SlackChannel` class implements the `Channel` interface for the Slack Web API. It supports sending plain text messages, rich Block Kit messages, reactions, and handling Slack event API callbacks for message reception.

Slack's Block Kit provides a powerful structured message format that allows for rich, interactive bot responses with buttons, menus, and formatted content.

## API Reference

### Constructor

```typescript
new SlackChannel(config: { token: string; signingSecret?: string })
```

| Parameter | Required | Default | Description |
|-----------|----------|---------|-------------|
| `token` | ✅ | — | Slack Bot token (`xoxb-...`) |
| `signingSecret` | ❌ | — | Signing secret for webhook validation |

### Methods

#### `sendMessage(channelId: string, text: string)`

Sends a plain text message to a Slack channel or conversation.

```typescript
await channel.sendMessage('C1234567890', 'Hello, Slack!');
```

#### `sendRichMessage(channelId: string, blocks: Block[])`

Sends a Block Kit message with structured content.

```typescript
await channel.sendRichMessage('C1234567890', [
  {
    type: 'header',
    text: { type: 'plain_text', text: 'Report Summary' },
  },
  {
    type: 'section',
    text: { type: 'mrkdwn', text: '*Status:* All systems operational' },
  },
  {
    type: 'actions',
    elements: [
      {
        type: 'button',
        text: { type: 'plain_text', text: 'View Details' },
        url: 'https://example.com',
      },
    ],
  },
]);
```

#### `getUser(userId: string)`

Retrieves user information by Slack user ID.

```typescript
const user = await channel.getUser('U1234567890');
console.log(user.real_name); // "John Doe"
```

#### `addReaction(channelId: string, timestamp: string, emoji: string)`

Adds an emoji reaction to a message.

```typescript
await channel.addReaction('C1234567890', '1234567890.123456', 'thumbsup');
```

Note: Reactions use the message timestamp as the identifier, not a message ID.

#### `openConversation(userId: string)`

Opens a DM or multi-party DM with users.

```typescript
const dm = await channel.openConversation('U1234567890');
console.log(dm.channel.id); // DM channel ID
```

#### `listChannels(types?: string, limit?: number)`

Lists accessible channels (public and private conversations).

```typescript
const channels = await channel.listChannels('public_channel,private_channel', 100);
```

#### `handleWebhookEvent(event: SlackEvent)`

Processes a Slack Event API callback and converts it to a `ChannelMessage`.

Handles event types:
- `message`: New messages in channels
- `app_mention`: Bot @-mentions
- `reaction_added`: Reaction events

## Authentication

Slack Bot tokens start with `xoxb-`:
```
xoxb-1234567890-1234567890123-AbCdEfGhIjKlMnOpQrStUvWx
```

### Getting a Bot Token

1. Go to [api.slack.com/apps](https://api.slack.com/apps)
2. Click "Create New App" → "From scratch"
3. Go to "OAuth & Permissions" in the sidebar
4. Under "Scopes", add these Bot Token Scopes:
   - `chat:write` — Send messages
   - `channels:read` — List channels
   - `reactions:write` — Add reactions
   - `users:read` — Read user info
   - `im:write` — Open DMs
5. Go to "Install App" → "Install to Workspace"
6. Copy the **Bot User OAuth Token**

### Signing Secret

For webhook validation, get the Signing Secret from:
**Basic Information → App Credentials → Signing Secret**

## Block Kit

Slack's Block Kit is a JSON-based message formatting system:

### Block Types

| Type | Purpose |
|------|---------|
| `header` | Bold title text |
| `section` | Text content (mrkdwn or plain) |
| `divider` | Horizontal line |
| `image` | Image with alt text |
| `actions` | Buttons, menus, overflow |
| `context` | Secondary text (gray, small) |
| `input` | Form input fields |

### Element Types (for actions blocks)

| Type | Purpose |
|------|---------|
| `button` | Clickable button |
| `static_select` | Dropdown menu |
| `multi_select` | Multi-select menu |
| `datepicker` | Date picker |
| `overflow` | Overflow menu |

### Message Example

```json
{
  "blocks": [
    {
      "type": "header",
      "text": { "type": "plain_text", "text": "📊 Daily Report" }
    },
    { "type": "divider" },
    {
      "type": "section",
      "text": {
        "type": "mrkdwn",
        "text": "*Revenue:* $12,345\n*Growth:* +5.2%"
      }
    },
    {
      "type": "context",
      "elements": [
        { "type": "mrkdwn", "text": "Generated by Agent Gateway" }
      ]
    }
  ]
}
```

## Message Reception

Slack uses the **Event API** for message delivery:

1. Configure the Event API URL in the Slack app settings
2. Slack POSTs events to your server's `/webhook/slack/events`
3. The adapter processes events and filters for messages

### Event Subscription

Subscribe to these events in the Slack app:
- `message.channels` — Messages in public channels
- `message.groups` — Messages in private channels
- `message.im` — Messages in DMs
- `app_mention` — When bot is @-mentioned

### URL Verification

When you first set the Event API URL, Slack sends a `url_verification` challenge:
```json
{ "token": "xxx", "challenge": "yyy", "type": "url_verification" }
```

The server automatically responds with the challenge value to complete verification.

## Rate Limits

Slack uses a tiered rate limit system:

| Tier | Limit | Applies To |
|------|-------|-----------|
| Tier 1 | ~1/s | `chat.postMessage`, `chat.postEphemeral` |
| Tier 2 | ~20/m | `conversations.list`, `users.list` |
| Tier 3 | ~50/m | `reactions.add`, `files.upload` |
| Tier 4 | ~100/m | Less common methods |

Rate limits are communicated via the `Retry-After` header on 429 responses.

## Error Handling

| Error | Behavior |
|-------|----------|
| `invalid_auth` | Token is invalid, channel disabled |
| `channel_not_found` | Channel doesn't exist or bot not invited |
| `not_in_channel` | Bot needs to be added to the channel |
| `missing_scope` | Bot lacks required OAuth scope |
| `rate_limited` | Waits `Retry-After`, retries |
| `account_inactive` | App was uninstalled from workspace |
